# Turno de estudio

Misiones cortas y lúdicas (3 a 8 minutos) para estudiar los ramos de Técnico en Prevención de Riesgos en IACC:
tarjetas, preguntas, casos aplicados, desafío del día y repaso relámpago de semanas pasadas.

- **Usar en el navegador:** https://estudioprevencion.funs.cl (copia de respaldo: https://tustracl.github.io/turno-de-estudio/)
- **App Android:** [descargar APK](https://estudioprevencion.funs.cl/turno-de-estudio.apk). Se actualiza sola con las semanas nuevas.

El avance se guarda en cada dispositivo. Para pasarlo de uno a otro, usa "Copiar respaldo" y "Restaurar respaldo" al final de la página.

El contenido es un resumen propio de estudio basado en el material de cada semana, con datos complementarios citados.
Este sitio se genera automáticamente; no edites estos archivos a mano.
